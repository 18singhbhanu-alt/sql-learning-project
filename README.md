# SQL Learning Project

## 📌 Introduction
This project is a beginner-friendly introduction to SQL (Structured Query Language).  
It explains database concepts, SQL commands, DBMS, MySQL installation, and real-world applications of SQL.

---

## 📖 Topics Covered

- Introduction to SQL
- What is a Database?
- What is DBMS?
- Types of SQL Commands
  - DDL Commands
  - DML Commands
  - DQL Commands
  - DCL Commands
  - TCL Commands
- SQL Examples
- Advantages of SQL
- Real-world Applications
- MySQL Installation Guide
